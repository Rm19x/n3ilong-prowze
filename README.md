#  Np  ( n3ilong prowze) - tools  N3i MyLove

---

##   Proyek

**Np**  adalah *script interpreter* dan *toolkit* multifungsi berbasis skrip kustom dengan ekstensi **`.Rm19`**. Mengusung sintaks intuitif berorientasi **Bahasa Indonesia**, Np Rm19 dirancang untuk mempermudah pemrosesan media (Audio, Video, Foto), analisis & optimasi **Web SEO**, serta fitur keamanan kode (*Code Obfuscation & Minification*).

> **Developer & Author:** Mr.Rm19 (Ramdan Maulana)  
> **Official GitHub:** [github.com/Rm19x](https://github.com/Rm19x)

---

##  FiTurEZET  (30+ Built-in Tools)

Toolkit **Np Rm19** terbagi ke dalam 3 kategori utama yang siap dieksekusi langsung dari kode `.Rm19`:

###  1. Pengolahan Media (Media Processing)
* **MP3 Merger:** Menyatukan beberapa file audio MP3 menjadi satu file utuh.
* **MP4 Video Joiner:** Menyatukan klip video MP4.
* **GIF to MP4 Converter:** Mengubah animasi GIF menjadi format video MP4 hemat memori.
* **Image Brightness & Contrast Enhancer:** Mencerahkan foto gelap dan mengatur kontras warna.
* **Image Sharpener:** Mempertajam detail foto buram.
* **Subtitle Embedder (Hardsub):** Menempelkan file subtitle (`.srt`) langsung ke video MP4.
* **Subtitle Extractor:** Merekstrak file subtitle dari dalam video.
* **SRT Sync Shift:** Memajukan atau memundurkan jeda waktu subtitle.
* **Audio Volume Normalizer:** Menyelaraskan tingkat volume file audio MP3.
* **Video Speed Changer:** Mengatur kecepatan pemutaran video MP4 (mempercepat/memperlambat).
* **Video Frame Extractor:** Mengambil foto/frame pada detik tertentu dari video.
* **Image Watermark Manager:** Menambahkan watermark teks atau memotong (*crop*) area watermark pada video.
* **MP3 Bitrate Converter:** Mengubah kualitas/ukuran file audio MP3 (contoh: 128kbps / 320kbps).
* **Batch Image Brightener:** Mencerahkan seluruh foto dalam satu folder secara otomatis.
* **Audio Extractor from MP4:** Mengekstrak suara MP3 dari video MP4.

###  2. Web SEO & Analisis Situs (SEO Tools)
* **Sitemap XML Generator:** Membuat sitemap XML otomatis untuk mesin pencari.
* **Robots.txt Generator:** Membuat file `robots.txt` standar SEO.
* **SEO Meta Tag Analyzer:** Menganalisis tag `<title>`, Open Graph, dan meta description.
* **SEO Heading Structure Checker:** Menganalisis hierarki tag `<h1>` hingga `<h6>`.
* **Broken Link Checker:** Mendeteksi tautan mati (404 Error) pada halaman website.
* **Keyword Density Counter:** Menghitung persentase kepadatan kata kunci dalam artikel/teks.
* **Canonical Tag Verifier:** Memeriksa keberadaan tag `rel="canonical"`.
* **SRT Subtitle Translator Helper:** Modul pembantu untuk translasi subtitle.

###  3. Keamanan & Pengacakan Kode (Code Obfuscation)
* **.Rm19 Code Obfuscator:** Mengacak nama variabel dan instruksi kode agar tidak mudah dibaca.
* **Script Minifier:** Menghapus spasi, tab, dan komentar untuk memperkecil ukuran file skrip.
* **Code Formatter:** Merapikan kembali struktur skrip `.Rm19`.
